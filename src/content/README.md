# Где что редактировать

| Что | Файл |
|---|---|
| Все фразы Кротика, вопросы, ответы, причины «за что люблю», предметы в тёмной комнате | `dialogues.js` |
| Воспоминания (First Hello и т.д.), фото, финальное письмо | `archive.js` |
| Секретная дата на входе, фото для пазла | `../config.js` |

## Фото
Клади файлы в `public/photos/` и пиши в `archive.js`:
`photos: ["photos/first-hello-1.jpg", "photos/first-hello-2.jpg"]`
Несколько фото листаются касанием. Фото для пазла: `public/photos/us.jpg`.
Видео для вопроса: `public/media/apple.mp4`, путь задаётся в `QUIZ.video`.

## Правила
- Меняй текст только внутри кавычек. Запятые и скобки не удаляй.
- В `dialogues.js` id сцен (второе значение у кнопок), `type` и `next` не трогай.
- Если сайт после правки перестал открываться, смотри ошибку в терминале с `npm run dev`: там будет указана строка.
